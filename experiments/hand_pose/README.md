# Human-like fretting pose: experiment log

Kept separate from the main project until it works. Nothing in `strum/`, `scripts/` or `assets/` has been changed. All outputs go to `outputs/hand-pose/` and `outputs/holds-human/`, which Git ignores.

## Goal

Visual appeal for the demo: the fretting hand as a person holds it (forearm level, palm up, under the neck, fingers curling up and over onto the fretboard), instead of coming down onto the strings from above. The strumming hand should strum at an angle with the back of the hand to the camera. This pose is only useful if all chords still play.

## Key facts that shaped the approach

- Calibration (`python -m strum.fretting calibrate`) takes only the **forearm mount** from the seed files. Every chord's finger pose is then solved from scratch by the IK planner (`strum/planner.py`). So a new pose needs no new finger data, only a mount where the fingers can reach.
- The right hand never touches the strings. Notes are counted when its fingertip crosses a string. Its angle is therefore free and needs no reachability check.
- The ukulele in the plain scenes and in the `--polished` scenes is the same instrument. `strum/presentation.py` only adds decorative, non-colliding parts on top.

## Files

| File | What it does |
|---|---|
| `check_hand_pose.py` | Searches forearm poses (yaw, pitch, roll, knuckle position) for one where the planner can play C, G, Am and F. Static: posed, no physics. Judges real contact like calibration and checks the approach path. Saves `best.json`, a `seed/` folder for calibration, and progress pictures. `--score` scores a saved pose. `--seed` picks the seed folder (fingerings and fingertip marker). |
| `render_poses.py` | Still pictures of poses, turned so the ukulele looks upright with the G string on top. Writes `outputs/hand-pose/previews/previews.md`. |
| `measure_pad_marker.py` | Measures where fingertips really touch the strings in a calibrated run and writes a seed folder with the fingertip marker moved there. |
| `idle_space.py` | `IdleSpaceHand`: the planner's hand, plus idle fingers that move out of the way of the pressing ones. |
| `calibrate_with_space.py` | Runs `strum.fretting calibrate` with `IdleSpaceHand`. Superseded by `fretting_with_space.py`. |
| `fretting_with_space.py` | Runs any `strum.fretting` command with `IdleSpaceHand`. Options: `--swing TILT` (swinging strumming hand), `--upright` (scene turned upright), `--right-angle DEG` (the rejected angled hand). |
| `right_hand.py` | Angled strumming hand. Rejected as not human-like (step 18); kept for the record. |
| `swing.py` | Swinging strumming hand: elbow hinge, curled fingers brushing the strings, down and up strokes. |
| `upright.py` | Turns the whole two-hand scene upright, with gravity turned too; a camera aimed at the fretboard. |
| `look.py` | Red concert-ukulele look: body shape, grain, rosette, fretboard, bridge, headstock, edges, heel, lighting. |
| `render_demo.py` | `stills` and `video` of the final scene, written to `outputs/demo/`. |

Swaps into project code (`Hand`, `add_right_hand`, `Strummer`, `decorate`) happen in memory, per run. Nothing in `strum/` is edited.

**Reproduce the final result** (outputs are not in Git; each step writes a new folder; `seed-contact-marker` comes from step 7, `measure_pad_marker.py`):

```bash
.venv/Scripts/python experiments/hand_pose/check_hand_pose.py --seed outputs/hand-pose/seed-contact-marker   # search, about 1 h
# copy the run's seed/ folder and set G to index C2, ring E3, middle A2 (step 15), then:
.venv/Scripts/python experiments/hand_pose/calibrate_with_space.py --placements <that seed> --output outputs/holds-human-4
.venv/Scripts/python experiments/hand_pose/fretting_with_space.py transition --run outputs/holds-human-4 --cycles 10 --two-hands --swing 8 --upright --output outputs/two-hand-check
.venv/Scripts/python experiments/hand_pose/render_demo.py stills
.venv/Scripts/python experiments/hand_pose/render_demo.py video
```

## Journey

Dates are 2026-11-19 to 2026-11-21. Runs are folders under `outputs/hand-pose/`.

1. **First quick search: every pose failed by 3 to 9 cm.** Today's mount, scored the same way, passed at 0.00 mm, so the pipeline itself worked.
2. **Bug: the palm direction was measured backwards.** The script curled the fingers from their rest pose, which is already bent about 70 degrees, so further curling moved the fingertips back toward the palm. Fixed by measuring from straight fingers. The pictures showed it: "palm up" poses had the fingers hanging down. Two searches run before the fix were discarded.
3. **Added:** a global search (differential evolution) instead of a local one; a second IK started from hook-shaped fingers, to tell "the hand can't reach" apart from "the planner can't find it"; naming of the part that cuts into something; and progress pictures every 5 generations, so mistakes show early. A short smoke test (`--generations 2 --popsize 3`) is run before every long search.
4. **Search with the corrected palm (run `20261119-175825`): static pass for all four chords.** Best pose: yaw -1, pitch +4, roll +2 degrees, knuckles 39 mm from the nut, 47 mm below the neck centre, 38 mm in front of the fretboard. The planner's own IK passed too, so the hook IK was not needed. Of 12 forearm directions, yaw -30 (angled toward the headstock) and 0 passed; -60 and +30 came close.
5. **Physics calibration of that pose (`outputs/holds-human`): all four chords failed.** Each pressing finger was on its correct string, held steady (drift under 0.2 degrees), but counted as unwanted.
6. **Cause: the fingertip marker.** The planner aims one marker point on the fingertip (site `ring_surface_reference`). It was measured for the old pose, where fingers come straight down. In the new grip, the real contact was about 3.5 mm further along the neck, just past the fret wire, so calibration scored each note as one fret too high (for example C's ring finger on A3 landed at 61.1 mm, while fret 3 ends at 60.6 mm). The static check had only checked the marker, not the real contact.
7. **Fix, part 1: moved the marker to the real contact spot.** `measure_pad_marker.py` averaged 12 real contacts: the marker moved 3.0 mm, from (-1.42, 1.02, 32.02) to (1.59, 1.11, 31.92) mm in the fingertip frame. The contacts spread up to 2.4 mm, because the rounded fingertip rolls. The result is in `outputs/hand-pose/seed-contact-marker/`.
8. **Fix, part 2: the static check now judges real contact like calibration does.** At each press pose, every fingertip contact goes through `classify_contact()`: own string, own fret, fretboard only inside its own fret. A wrong note fails the pose and costs 5 in the search. Validation: with the old marker it reproduces calibration's wrong notes exactly (C RF:A3>A4, G MF:C2>C3, G RF:E3>E4, Am MF:G2>G3, F MF:G2>G3).
9. **Same pose with the new marker: only G's index finger is still wrong** (A2 lands in fret 1). G puts two fingers on fret 2 and the planner spreads them to opposite ends, leaving the index finger 2 mm from the fret wire, which is less than the 2.4 mm the contact can roll.
10. **Search with the new marker and the strict check (run `20261121-021900`): static pass for all four chords, with the planner's own IK.** Best pose: yaw -8, pitch -4.5, roll +14 degrees, knuckles 29 mm from the nut, 60 mm below the neck centre, 28 mm in front of the fretboard. It first passed at generation 20 and was stable from generation 30. No planner change was needed for G after all. Yaw comparison: 0 passes; -30 now fails (G's index finger runs out of room), so a slant of about -8 to 0 degrees is what works. Note: in its table, "current mount" fails G too. That is expected, because the new marker describes the new grip, not the old one.
11. **Physics calibration of that pose (`outputs/holds-human-2`): every chord plays and holds, but only C is accepted.** Holds: C, Am, F and G all held 100% of the 10 s screen with no unwanted contact (0.12–0.37 N per pressed string), and C also held for 60 s. What fails is the approach, which moves from the rest pose into the chord in one rollout (reach 1 s, press 0.5 s) with no unwanted contact allowed. In Am and F the middle finger bumps the ring finger while reaching for the G string (middle and proximal segments touching, 24% of the reach, 61% of the press). In G the index fingertip briefly touches the A string outside its note while pressing. Gap: the static check judges only the final chord pose, not the movement into it. Chord changes in the demo use the same lift, move and press motion and the same rule, so the movement has to be checked too.

12. **Replayed the Am approach and drew it** (`outputs/hand-pose/approach/`). The middle finger reaches the G string only by splaying sideways to its limit (J4 = 0.35 rad, which is the joint's limit of 0.349), while the ring finger stays curled in its rest pose right next to it. They first touch at 76% of the reach and press against each other (2.35 N at the hover point, 0.86 N while pressing). The static check passed because it only looked at the final press pose, not the hover point 10 mm above it or the path between. Also visible: in this grip the rest pose already lays all four fingers over the fretboard, close together, so any sideways move of one finger meets its neighbour.

13. **Idle fingers make room (`idle_space.py`), and the static check now covers the approach.** `IdleSpaceHand` places the pressing fingers exactly like the planner, then gives each idle finger the shape (out of 27 combinations of spread, knuckle and outer joints) that keeps it at least 3 mm clear of the other fingers, the thumb and the ukulele along rest, hover and press, choosing the one closest to the normal rest pose. `check_hand_pose.py` now samples the approach (rest to hover to press, same easing as calibration) and reports finger clashes and wrong touches. On the pose from step 10: the planner and hook IK fail with `Am path clash:MF/RF, F path clash:MF/RF`, matching the physics failure; with idle fingers making room, all four chords pass. Chosen idle shapes: in Am and F the ring finger spreads away (J4 -0.3) and straightens (J3 0.6), lifting clear. The G index finger touching the A string while pressing, seen in physics, does not show in the static path, so it is a dynamic effect for calibration to judge.

14. **Physics calibration with idle fingers making room (`calibrate_with_space.py`, `outputs/holds-human-3`): C, Am and F fully accepted** (clean approach from rest, 100% held for 60 s, no unwanted contact). The script points calibration's `Hand` at `IdleSpaceHand` in memory only. **G still fails its approach** at every press depth: while holding, the index finger (assigned A fret 2) also touches the A string on the nut side of the fret-2 wire (21.4 mm), so part of its contact counts as fret 1 (unwanted 29–100% of the hold, depending on depth). The target note itself sounds (A at 0.05–0.4 N). Cause: G has two fingers on fret 2, so the planner places the index finger only `FRET_MARGIN` = 2 mm inside the wire, less than the ~2.4 mm the rounded fingertip contact spreads. The static check cannot see this: its exactly placed contact is inside the fret.

15. **Standard G fingering: all four chords accepted with physics (`outputs/holds-human-4`, `ALL FOUR VERIFIED: True`).** The project's G used middle on C2 and index on A2. The usual chart fingering is index C2, middle A2, ring E3. Set in an experiment seed only (`outputs/hand-pose/seed-g-chart/`; `assets/` unchanged). Static check: pass. Physics with idle fingers making room: C, Am, F at press depth -0.75 mm and G at -0.5 mm (its -0.75 mm try failed the approach). All four: clean approach from rest, 100% held for 60 s, no unwanted contact. Tilting the hand was not needed.

    **Everything the grip needs, compared with the project as it is:** the forearm pose from run `20261121-021900`; the fingertip marker moved 3.0 mm (step 7); idle fingers making room (`IdleSpaceHand`, a planner change if adopted); the standard G fingering (a chord-table change if adopted).

16. **Chord changes in the new grip: 10 of 10 training changes pass** (`fretting_with_space.py coverage`, `outputs/coverage-human-4`). Every change, both changes into G included, reached and held its destination 100% with no unwanted contact during the move or the hold. The held-out changes (Am to G, F to C) were not run, as the benchmark rules require. `fretting_with_space.py` generalizes `calibrate_with_space.py`: it swaps `IdleSpaceHand` in, in memory, for any `strum.fretting` command.

19. **Strumming hand rebuilt as a real swing (`swing.py`, `fretting_with_space.py --swing TILT`).** Step 18's angled hand was rejected as not human-like. ## Lessons

- Check a pose by the same rule that will judge it later. A static "the marker reached its target" pass was not a real pass.
- Look at pictures early. The palm bug was obvious in a picture and invisible in the numbers.
- Smoke-test the whole script before a long run.
- Physics calibration stays the final word: it found the index finger in G sliding beside the A string, which a static check cannot see.
- When a picture looks odd, measure before guessing. The dark headstock crown came from inward-facing mesh faces; a face-orientation count found it directly, after a first guess was wrong.
